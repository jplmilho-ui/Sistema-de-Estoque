Atualizações do Projeto
- Sobre as alterações

Nesta versão do projeto foram realizadas algumas melhorias e alterações no sistema, com foco na organização das informações, experiência do usuário e controle de acesso.

- Novas funcionalidades
Tela de Movimentações: adicionada uma nova tela para visualização e gerenciamento das movimentações realizadas no sistema.
Tela de Materiais: adicionada uma tela destinada ao gerenciamento e acompanhamento dos materiais cadastrados.
- Alterações no design
Tela de Login: o design da tela de login foi atualizado, proporcionando uma interface mais moderna e organizada.
- Alteração no cadastro de usuários
A tela de cadastro de usuários foi removida do sistema.
O cadastro das pessoas será realizado internamente pela equipe responsável, evitando que novos usuários possam realizar o próprio cadastro.

- Resumo

As principais mudanças realizadas foram:

Adição da tela de Movimentações.
Adição da tela de Materiais.
Atualização do design da tela de Login.
Remoção da tela de Cadastro.
O cadastro de pessoas será realizado pela equipe responsável pelo sistema.
